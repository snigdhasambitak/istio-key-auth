# Security policy

Please do not open a public issue for a vulnerability. Report it privately through
[GitHub security advisories](https://github.com/snigdhasambitak/istio-key-auth/security/advisories/new).

Include what you found, how to reproduce it, and the version or commit. You will get an answer within a week. Fixes
are released as a patch version, and the advisory is published once a fixed release is available.

Only the latest minor release receives security fixes.
